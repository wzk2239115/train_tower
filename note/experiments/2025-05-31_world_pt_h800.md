| 参数 | 值 |
|------|-----|

| datasets | `blip3o_long_pt`, `blip3o_short_pt` |

| loss_weights | CE 0.0, FM 0.0（JEPA / tower 语义阶段） |

| learning_rate | 2.0e-4，warmup 500 |

| save_steps | 5000，`save_total_limit: 2` |

| deepspeed | `configs/deepspeed/zero2.json` |
